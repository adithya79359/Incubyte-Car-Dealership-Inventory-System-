Place vehicle photos in this folder using simple filenames, such as `toyota-fortuner.jpg`.

Supported formats: JPG, JPEG, PNG, WebP, and AVIF. In the vehicle editor, enter `/cars/toyota-fortuner.jpg` as the image path. Run `npm run build` again when adding images while using `npm start`.

Use photos you own or have permission to distribute. External HTTPS image URLs remain supported.
